## визначення ролей при регестрації

- проблема: після регестрації або вході на платформу не зрозуміло як буде відбуватися визначення ролі (streamer та viewer)
- рішшення: замість виділення окремої сутності під кожну роль було принято рішення об'єднати ці дві ролі в одній сутності та визначати поточну роль місцем перебування користувача:
  власний канал чи стрім - користувач перебуває в ролі стрімера
  канал чи стрім іншого користувача - перебування в ролі глядача

- примітка: ці ролі не будуть фіксуватись а являтимуть собою умовний поділ

## взаємодія user з chat

- проблема: user при написанні повідомлення не може просто додавати текст в загальну купу символів створену через використання чату багатьмя користувачами
- рішення: виділення окремої сутності message який буде відображатись в чаті через список в атрибуті chat - array

## призначення ролей користувачем на власному каналі

- проблема: при призначенні ролей інформація ніде не зберігається тому не відбувається ніяких змін після цього
- рішення: створення окремого атрибуту в сутності user (vip_list) який зберігатиме id всіх глядачів що були виділені

## обмеження пов'язаних з девайсом

- проблема: можливість відстеження девайсу
- рішення: поки ця можливість відкинута і прибрана з вимог
