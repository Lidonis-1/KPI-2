## Сутності:

- User - зареєстрований користувач платформи. Може виступати в ролі глядача (переглядати стріми, писати в чат, оформлювати підписки) або в ролі стрімера (створювати та вести власні трансляції). Користувач може мати лише одну активну сесію (пристрій) та проводити не більше одного стріму одночасно, зберігає інформацію про людей які на каналі користувача матимуть привілегії;
- Stream - активна пряма трансляція що має відповідні елементи: відео, чат, кнопка оформлення підписки та додання в улюблене канал користувача що веде стрім;
- Chat - елемент стріма що має поле з введенням повідомлення та історією повідовлень;
- Video - картинка прямої трансляції;
- Subscription - підписка, що може бути оформленна кожен місяць і кошти за оформлення якої частково йдуть на рахунок каналу;
- Message - повідомлення надіслане користувачем в чат стріма.

## Зв'язки між сутностями:

- user -> subscription - 1:N один користувач як subscriber може оформити від 0 до безліч підписок, але кожна підписка може належати лише до 1 subscriber. так само із user в ролі streamer;
- user -> stream - 1:N один користувач (streamer) може мати від 0 до безліч стрімів але лише 1 в активному статусі. Cтрім може належати лише до одного стрімера;
- stream -> user - N:N один стрім може мативід 0 до безліч user (viewer), водночас один глядач може переглядати від 0 до безліч стрімів за раз;
- stream -> chat - 1:1 кожен стрім має власний 1 чат, кожен чат належить лише 1 стріму;
- stream -> video - 1:1 кожен стрім має власне 1 відео, кожне відео належить лише одному стріму;
- chat -> message - 1:N кожен чат може мати від 0 до безліч повідомлень, кожне повідомлення належить лише 1 чату;
- user -> message - 1:N кожен юзер може мати від 0 до безліч повідомлень, кожне повідомлення належть лише 1 користувачу.
