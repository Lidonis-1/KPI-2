# Обраний домен - Стримінгова платформа

## Мета проекту

- Cтворення платформи основою якої є можливість користувачів транслювати власну активність на платформі та збирати аудиторію що приноситиме дохід через внутрішньосистемні операції.
- Створення додаткових можливостей для розповсюдження реклами компаній та брендів через колаборацію із стрімерами тим самим даючи додаткові можливості для заробітку користувачам платформи.

## Опис функціоналу:

- Регестрація акаунту з якого відбуватимуться основні операції на платформі. (при регестрації потрібно обов'язково вказати ім'я, номер тел., електронну пошту та вік)
- Початок відео-трансляції з зарегестрованого акаунту з можливістю модерувати його та призначати модераторів в межах каналу. (стрім після завершення трансляції переводиться в стан завершений та зберігається на сторінці каналу. За потреби може бути видалений автором)
- Перегляд трансляції інших користувачів та взаємодія з елементами стріму
- при наявності в глядача ролі модератора, можливість модерувати стрім іншого користувача
- Оформлення та подовження підписки на канал для отримання винагород від стрімера який і визначає їх
- Додання до списку збережених інших користувачів.

## Ролі передбаченні функціоналом платформи на трансляції:

- Стрімер
- Глядач
- Підписник
- Модератор

## Опис навігації платформи

Навігація на платформі повинна відбуватись з забезпеченням інтуїтивної зрозумілості користувачу та мінімальними діями для переходу до елементів сайту, також платформа повинна бути виконана в одному стилі що найкраще сприйматиметься при довготривалому перегляді з швидким пошуком важливих для взаємодії з платформою частин.

## системні обмеження платформи:

- на кожну електронну пошту, телефон та електронні гаманці може бути прив'язаний лише один користувач;
- кожен користувач може проводити лише один стрім одночасно
- один користувач може бути активний лише з одного пристрою
- регестрація з одного пристрою може бути виконана лише раз на 1 хвилину
